## 运行和数据边界

| 组件 | 依赖与数据流 |
| --- | --- |
| Agent整理需求 | 使用现有宿主，把用户需求组织为Skill请求；宿主模型费用另计 |
| 核心二创与修订 | 官网账号认证后调用私有服务，核心算法不随开源包分发 |
| 参考搜索 | Node.js22+，官网HTTPS计量接口；游标翻页最多5页/1小时，不额外扣搜索次数 |
| 原文读取与下载 | 遵守现行复制权限及完整性校验；下载只写显式指定的新私有文本文件 |
| 图片/视频生成 | 本版不执行，不包含媒体生成额度 |

客户端无npm依赖、模型SDK或自动素材上传。网站匿名浏览仍按原规则运行；本版Skill的搜索和二创需要账号。案例链接、作者和模型标签不证明许可、复现成功或跨模型可用。Loopback调试不作为正式接口证据。
