真实受限原文、登录会话的新原文端点和媒体质量仍未验证。模型、源站数据和权限可能变化，实际请求结果优先于文档中的历史观测。

## 运行和数据边界

| 组件 | 依赖与数据流 |
| --- | --- |
| Agent 文字创作 | 使用你现有的宿主与模型额度，按照 `SKILL.md` 交付文字 |
| 参考检索与原文 | Node.js 22+，默认通过 HTTPS 读取 PromptPlaza API；请求和权限仍受服务规则约束 |
| 原文下载 | 显式指定的新私有本地文本文件；不覆盖现有内容 |
| 图片/视频生成 | 不在 Basic 包内，不包含生成额度 |
| 高级 Creative 服务 | 尚未开放，私有服务端核心不随本仓库分发 |

没有 npm 依赖、模型 SDK、自动素材上传或生成供应商调用。案例链接、作者和模型标签属于来源信息，不构成权利认证、复现成功或跨模型可用的证据。

## 版本与文档

`main` 上的使用文档可独立更新；安装命令固定到不可变 tag。已经发布的 beta.7 tag 与 ZIP 不因文档更新而重打包。需要新的代码或 Skill 指令时，维护者先完成限定验证，再发行新版本并更新这张表。

本页只记录可以公开分享的验证摘要，不包含访问凭据、第三方提示词正文、个人会话或内部服务配置。更新记录见[变更日志](../CHANGELOG.md)。
