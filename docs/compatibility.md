## 可参考的历史证据

- **beta.7，2026-11-14**：当前公开 ZIP 大小、SHA 与九文件匹配；实际完成图片/视频检索、作者和时长组合筛选、两条原文读取、一条 866 字节原文下载、空结果和缺失案例恢复。下载重复目标和项目内目标在请求前拒绝。首轮空查询选词不当及一次 GitHub 连接超时分别保留，续验没有覆盖这些失败。
- **beta.7 宿主发现**：项目安装后，真实 Codex skills/list 返回该 Skill；不代表模型已读取或执行，也不证明 beta.8 的宿主验收。两版本的 SKILL.md 指令相同。
- **beta.6**：完成过图片/视频检索、两条原文读取及 866 字节下载，不能替代当前版本接口证据。
- **beta.5**：指定 Codex 视频文字任务及逐问交付任务执行通过；只生成文字，不证明图片/视频效果。

真实受限原文、登录会话的新原文端点与撤销、媒体质量仍未验证。模型、源站数据和权限可能变化，实际请求结果优先于文档中的历史观测。

## 运行和数据边界

| 组件 | 依赖与数据流 |
| --- | --- |
| Agent 文字创作 | 使用你现有的宿主与模型额度，按照 SKILL.md 交付文字 |
| 参考检索与原文 | Node.js 22+，远程仅通过官方 HTTPS API；请求与权限仍受服务规则约束 |
| 原文下载 | 显式指定的新私有本地文本文件；不覆盖现有内容 |
| 图片/视频生成 | 不在 Basic 包内，不包含生成额度 |
| 高级 Creative 服务 | 尚未开放，私有服务端核心不随本仓库分发 |

没有 npm 依赖、模型 SDK、自动素材上传或生成供应商调用。案例链接、作者和模型标签属于来源信息，不构成权利认证、复现成功或跨模型可用的证据。Loopback 调试响应也不能作为官方案例的验收证明。

## 版本与文档

main 上的使用文档可独立更新；安装命令固定到不可变 tag。旧 beta.7 tag 与 ZIP 保留。beta.8 修复客户端来源与搜索反馈边界，创作指令与免费功能范围不变；后续版本须完成自己的限定验收。

本页只记录可公开分享的验证摘要，不包含凭据、第三方提示词正文、个人会话或内部服务配置。更新记录见[变更日志](../CHANGELOG.md)。
